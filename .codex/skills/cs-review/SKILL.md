## 검토 지침
위의 변경 내용 추출 diff 명령어를 통해서 다음을 지적하라.
 - Update 안에 GetComponent나 Find가 존재하는가?
 - 각 클래스는 과도하게 큰 GOD Class 설계되지 않았는가?
 - SOLID 규칙을 지켜서 만들어졌는가?
 - 의존은 구체적 클래스가 아닌 인터페이스나 추상 클래스를 통해 이루어지는가?
 - public 필드를 남용하고 있지 않은가?
 - 힙 메모리 할당이 과도하게 이루어져 성능 하락이 의심되는 구간이 있는가?

각 항목 검토 시 파일 : 라인과 수정 제안을 함께 붙일 것.
설명은 장황하지 않고 간결하게 설명할 것
